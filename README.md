# ZenMultiLogin — instaladores

Este repositório guarda apenas os **instaladores** do ZenMultiLogin. O app instalado verifica as versões novas aqui e se atualiza sozinho.

- **Baixar:** abra a [última versão](https://github.com/hypegroupengaja-netizen/zenmultilogin-releases/releases/latest) e baixe `ZenMultiLogin-Setup-x.y.z.exe`.
- Na primeira vez, o Windows pode avisar que o app não tem assinatura digital. Clique em **Mais informações → Executar assim mesmo**.
- Depois de instalado, não precisa baixar de novo: ao abrir, o ZenMultiLogin baixa e instala as atualizações sozinho.

O código-fonte não fica neste repositório.
